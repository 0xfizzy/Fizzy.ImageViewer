A viewer-owned measurement handle. Operations dispatch synchronously to the viewer STA; callbacks run on that STA. Dispose is idempotent and safe after viewer closure. Id, Origin and IsDisposed remain readable after closure; other access requires a running viewer.

public interface IMeasurement : IDisposable

Remarks

Disposal attempts query revocation, callbacks, resources and visual cleanup, aggregating failures. Failed cleanup is not retried by later disposal. Independently retained geometry and query snapshots remain usable.

Transfers sole cleanup responsibility to this measurement on successful return. Each accepted instance is disposed once during measurement cleanup.

Remarks

On failure no ownership changes: a previously unowned resource remains the caller's responsibility; a duplicate remains owned by this measurement. Do not register resources already owned by another measurement or owner.

GeometryChanged

Reports changed geometry on the viewer STA after model and visual updates; subscriber failures are isolated.

event EventHandler<MeasurementGeometry>? GeometryChanged

Event Type

EventHandler<MeasurementGeometry>

Remarks

Sender is the measurement handle. Adding a subscriber rejects a removed measurement or stopping viewer with ObjectDisposedException; removing one is always safe. Duplicate subscriptions follow delegate semantics. Notifications share the measurement FIFO queue; reentrant changes follow the current mutation. Payloads are immutable snapshots; the handle may already have changed or been removed. Unsubscription does not retract captured notifications; subscriptions added during delivery apply only to later notifications. Synchronous subscriber failures are logged and isolated. Async-void work is not awaited; subscribers own its failures.
