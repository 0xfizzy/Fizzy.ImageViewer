Displays images, drawings and measurements in an independently owned WPF window.

Creates its WPF window on an independent STA; facade calls marshal to that thread. Borrowed tool contexts retain their own callback-thread restrictions.

SetDisplayRangeAsync(GrayDisplayRange?)

Sets the requested mapping and waits for a corresponding display commit. With no current frame, configures future submissions and completes immediately. A non-null range on a current GPU frame throws synchronously without changing the request. A later setting or Viewer shutdown cancels a pending update. Preparation or presentation failure faults the task; the requested value remains set and the previous committed mapping remains available to snapshots. Success is a UI commit, not physical presentation.
