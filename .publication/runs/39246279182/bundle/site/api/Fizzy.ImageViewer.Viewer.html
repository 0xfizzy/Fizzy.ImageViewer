Displays images, drawings and measurements in an independently owned WPF window.

Creates its WPF window on an independent STA; facade calls marshal to that thread. Borrowed tool contexts retain their own callback-thread restrictions.

WhenStopping

Gets the shared task that completes successfully when the viewer stops accepting new work.

public Task WhenStopping { get; }

Property Value

Task

Remarks

Reading or awaiting this task does not initiate shutdown. It remains completed for late observers and never faults or cancels, including when subsequent cleanup fails. Completion does not mean accepted work has drained, resources have been released, or the standalone STA has exited. The owner must still await IAsyncDisposable.DisposeAsync. Temporary unloading does not complete this task. Continuations are not invoked inline by the signal; no UI-thread delivery is promised. Concurrent operations must still handle shutdown rejection and honor frame ownership transfer.

Closed

Window closure notification on the viewer STA. Owners must still await IViewer.DisposeAsync to drain background work and wait for actual STA termination. Runs after queued measurement notifications.

public event EventHandler? Closed

Event Type

EventHandler

Remarks

Sender is the public object that owns this event. Adding a subscriber rejects a stopping viewer with ObjectDisposedException; removing one is always safe. Duplicate subscriptions follow delegate semantics. Unsubscription does not retract captured notifications; subscriptions added during delivery apply only to later notifications. Synchronous subscriber failures are logged and isolated. Async-void work is not awaited; subscribers own its failures.
