Remarks

Session and unfinished-measurement cleanup are all attempted. Failures propagate to the caller, aggregated when multiple stages fail; cleanup is not retried.

RegisterMeasurementTool(IMeasurementTool)

Registers a custom tool; CreateSession creates a fresh session for each activation. Create previews through IMeasurementToolContext.CreateMeasurement. Complete retains the result; the viewer owns cancellation, removal, clear and shutdown cleanup. Schedulers, arbitrary geometry implementations and per-frame query registration are not public extension points.
