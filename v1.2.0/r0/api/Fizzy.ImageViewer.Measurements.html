Interfaces

IMeasurement

A viewer-owned measurement handle. Operations dispatch synchronously to the viewer STA; callbacks run on that STA. Dispose is idempotent and safe after viewer closure. Id, Origin and IsDisposed remain readable after closure; other access requires a running viewer.

IMeasurementTool

Reusable tool registration. Each activation creates an independent session on the viewer STA.

IMeasurementToolContext

Capabilities borrowed by custom tools on the viewer STA. Tool callbacks and creation operations must run on that STA; returned measurement handles dispatch themselves. Each factory receives a context for one activation and passes it to its session. Ended contexts reject new measurements.

IMeasurementToolSession

One activation of a measurement tool. Callbacks run on the viewer STA. Dispose is called exactly once after completion, interruption or callback failure. Cancellation notification is separate from unconditional session-resource cleanup.

IViewerMeasurements

Measurement tools, interaction, style and notifications on the viewer STA.
