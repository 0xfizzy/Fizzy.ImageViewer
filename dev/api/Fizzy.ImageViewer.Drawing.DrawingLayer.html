DrawingClicked

Raised on the viewer thread for a drawing hit. Subscriber failures are logged independently; a hit consumes the mouse event even if a subscriber fails. Adding handlers dispatches to the viewer STA and rejects removed layers or a stopping viewer. Removing handlers remains safe after layer removal or viewer closure.
